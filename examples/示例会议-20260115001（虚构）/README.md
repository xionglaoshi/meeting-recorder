# 示例会议（**全部虚构**）

本目录内容**纯属虚构**，只为让人一眼看懂「一场会议跑完会产出什么」。

- 公司/项目/人名都是编的（甲乙双方、星辰项目、张伟/李娜/王强…）
- 结构、文件清单、字段与你自己的真实记录**完全一致**
- 真实记录会落在 `../../records/<日期><序号>/`，那个目录不进 Git

| 文件 | 谁写的 | 作用 |
|---|---|---|
| `metadata.json` | 程序 | 会议元数据（标题/参会人/时长/句数/生成时间） |
| `会议记录-流水.md` | 程序（实时） | 逐句流水，带序号与时间 |
| `会议记录-清洗稿.md` | 程序（L1） | 去口水词/去重复后的稿子 |
| `纠错对照清单.md` | 程序（L2） | 模型改了什么，一条一行，可回滚 |
| `实体核验-待确认.md` | 程序 | 人名/公司名等实体拿不准的，列出来问你 |
| `存疑清单.md` | 程序 | 语义存疑、需要你确认的点 |
| `会议纪要.md` | 程序 | 正式纪要（你要的那份） |
| `补充信息.md` | 你 | 会中/会后随口补充（旁白、叮嘱），可选 |
| `task.log` | 程序 | 处理日志 |
